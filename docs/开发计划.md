# eChinese 客户端开发计划

## 一、范围

- 平台：Android（KMP 结构，iOS 二期）
- 语言：Kotlin + Jetpack Compose
- 一期：登录注册、目标、学习首页、练习框架与 10 类题型、考试、复习
- 不做：离线学习、社区、支付、教师端、AI 对话

## 二、阶段

| 阶段 | 周期 | 目标 | 验收 |
|---|---|---|---|
| P0 骨架 | 2 周 | 工程、主题、路由、登录/注册/目标、空首页 | 真机完成注册→目标→首页 |
| P1 内容 | 4 周 | 内容包、单元页、练习框架 + 前 5 个题型 | 目录→单元→做题闭环 |
| P2 题型 | 3 周 | 补齐声调、短文、跟读、部首识字、部件多选 | 10 类题型可跑 |
| P3 考试 | 2 周 | 小测、计时、答题卡、交卷、成绩 | 可交卷出分 |
| P4 复习与打磨 | 2 周 | 错题本、待复习、Bugly、性能包体 | 崩溃率与包体达标 |

合计 13 周，另留 1–2 周缓冲。

## 三、P0 任务拆解

### 第 1 周
- [x] 工程骨架（app/core/domain/data/feature:auth）
- [x] 主题 token
- [x] 登录页（mock 数据）
- [ ] 注册页 + 找回密码
- [ ] 会话状态（登录态保存、退出）
- [ ] 底部导航与首页壳

### 第 2 周

- [ ] 首页：今日任务卡片 + 进度
- [ ] 我的：资料、语言、退出
- [ ] 网络层骨架（接口占位 + mock 开关）
- [ ] 崩溃监控接入（Bugly，仅正式包）
- [ ] 首轮真机走查与修复

## 四、工程约定

- 分支：`main` 稳定；功能分支 `feat/xxx`，修复 `fix/xxx`
- 提交：中文，`类型: 说明`，如 `feat: 新增注册页`
- 模块依赖：app → feature → domain → core；feature 不直接依赖 data 实现
- 接口未定：data 层 mock，接口就绪只替换实现
- 每个页面必须有：加载、空、错误三态

## 五、质量门禁

- 编译通过 + 关键页面单测；
- 每新增题型截图回归；
- 发版前：崩溃率、启动耗时、包体增量；
- 新依赖需说明体积与启动影响。

## 六、风险

| 风险 | 应对 |
|---|---|
| 后端接口延迟 | mock 先行，接口层隔离 |
| 题型 schema 变更 | 第一版冻结，只增不删 |
| 语音评分未定 | 先做录音与上传，评分接口留空 |
| 内容不足 | 先用 1 单元 20 题打通 |
| 包体/性能 | 每阶段实测，超预算即停 |
